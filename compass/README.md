# COMPASS analysis code

Source code and methods for donor-level MuSC metabolic analyses. BI13 uses Young 7 / Older 6; age-stratified associations use Young 7 / Older 14. Results are exploratory and input-size controls demonstrate sampling sensitivity.

## Reproduction

Install dependencies with `python -m pip install -r compass/requirements.txt`. This code-only submission requires the matching local `compass_manuscript_release` data and tables directories. Place those directories under `compass/`, then run `python compass/code/reproduce.py`. Figures and derived tables are written under that directory. The raw validation record and historical grid are preserved inputs rather than regenerated by this entry point.

This PR does not include the derived data package or figures; a fresh clone alone cannot reproduce the results. Optional solver commands are in code/run_compass.sh and require COMPASS and licensed CPLEX. Original execution provenance remains in the local full package.

## Code availability

Custom analysis code is supplied in this repository's compass directory. The accompanying source-data package remains local pending deposition. The figure/source map documents expected inputs and outputs.
